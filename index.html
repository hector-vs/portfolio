Polls API

API de enquetes em tempo real desenvolvida em TypeScript e Node.js, utilizando Prisma e Docker Containers. Através de requisições HTTP, é possível criar enquetes e suas opções, enquanto os votos são registrados e exibidos em tempo real por meio de WebSockets. O projeto também conta com medidas de prevenção contra ataques e invasões. Seu desenvolvimento foi importante para consolidar e colocar em prática conhecimentos técnicos relacionados ao desenvolvimento de APIs, comunicação em tempo real e infraestrutura.

Tecnologias:

Typescript, NodeJS, Prisma, Docker, HTTP e WebSockets

Github

Website rápido, prático e funcional de memorização da tabuada. Nele, são feitas perguntas rápidas sobre a tabuada de multiplicação, treinando o pensamento matemático e fixando os números na mente. Pass In

API de gestão de participantes em eventos presenciais, permitindo que organizadores cadastrem eventos e disponibilizem páginas públicas para inscrição. Os participantes podem emitir suas credenciais, que são escaneadas no dia do evento para validar e registrar sua entrada. O desenvolvimento do projeto também contribuiu para consolidar conhecimentos técnicos, colocando em prática conceitos de desenvolvimento de APIs, gerenciamento de dados e criação de soluções voltadas a necessidades reais.

Tecnologias:

Typescript, NodeJS, Prisma, Fastify (rotas) e Zod
